# Feature checklist for AI mobile app builders

Every competitor is scored on the same rows so the matrices merge. For each row, record:
- **✅** has it
- **◐** partial or limited (say how)
- **❌** doesn't have it
- **?** couldn't verify

Add the evidence link and the date checked. Use only live product pages, docs, changelogs, pricing pages and official demos. Treat third-party claims as "reported".

## 1. Input
- Text prompt
- Image or screenshot to app
- Figma import
- Voice input
- Reference app or URL ("make it like X")
- Plan or spec step before building (screens list, user flow)

## 2. Generation
- Output stack:
  - Expo / React Native
  - SwiftUI
  - Kotlin
  - Flutter
  - Webview
- Multi-screen apps, and any stated screen limit
- Design system or theming
- Brand kit
- Iterating by chat
- Visual editor (click to edit)
- Code view and edit in the browser
- Code export or download
- GitHub sync
- Version history and rollback
- Error auto-fix (self-healing builds)

## 3. Preview and testing
- Web preview
- On-device preview (Expo Go or QR code, own companion app)
- iOS simulator
- TestFlight builds
- Android APK

## 4. Backend and data
- Built-in database (own, Supabase, Firebase, Convex)
- Auth: email, Apple, Google
- File storage
- Server functions or API routes
- Secrets handling (no keys in the client)
- Third-party API integrations

## 5. Monetization
- In-app purchases and subscriptions via StoreKit / RevenueCat
- Paywall templates
- Stripe (web)
- Ads (AdMob)
- Analytics

## 6. Native capabilities
- Camera
- Push notifications
- Location
- HealthKit
- Widgets
- Haptics
- Offline storage
- AI/LLM calls inside the generated app

## 7. Publishing (the "last mile")
- Cloud build (EAS or own)
- Code signing handled
- Upload to App Store Connect
- Submission to App Store review
- Google Play upload
- App Store metadata or ASO help (title, keywords, description)
- Screenshot generation
- Privacy labels / privacy policy help
- Pre-flight check against App Store guidelines
- Rejection help
- Over-the-air updates

## 8. Platform and workflow
- Web app
- Desktop app
- Mobile app (build from a phone)
- Team collaboration
- Templates gallery
- Docs and tutorials
- Community (Discord etc.)
- Support channel

## 9. Pricing
- Free tier
- Paid plans: price, credits or messages per plan, overage price
- What costs a credit
- Annual discount
- Refund policy
- Limits (projects, builds, apps published)

## 10. Company
- Funding and investors
- Launch date
- Users or revenue claims (marked "claimed")
- Ads running (Meta Ad Library: active count, longest-running)
